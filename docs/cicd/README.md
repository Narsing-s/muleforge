# MuleForge CI/CD

MuleForge treats CI/CD as an extension of the generated project, not as a replacement for GitHub Actions, GitLab CI, Azure DevOps or Jenkins.

## Available now

- GitHub Actions CI workflow
- CLI test execution
- Generated-project verification
- Secret-hygiene gate
- CI artifact collection

## Planned

- `muleforge cicd init`
- GitLab CI template
- Azure DevOps template
- Jenkins template
- CloudHub deployment templates
- CloudHub 2.0 deployment templates
- Runtime Fabric deployment templates
- Environment promotion helpers

See [GitHub Actions](github-actions.md) for setup and security guidance.
