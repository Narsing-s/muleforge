## Generated project documentation

MuleForge also creates a separate `docs/` directory inside generated applications. That documentation describes the specific application's requirements, solution design, API, flows, DataWeave, configuration, tests and deployment steps.

The repository documentation here explains **MuleForge itself**. Generated project documentation explains **the application created by MuleForge**.
