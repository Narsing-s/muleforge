# 🚀 MuleForge

## Define once. Generate everything. Build faster with MuleSoft.

MuleForge is an open-source CLI and developer toolkit for generating Mule 4 API projects from a simple declarative configuration.

Instead of manually creating and configuring:

- RAML
- Mule XML flows
- DataWeave
- Maven `pom.xml`
- `mule-artifact.json`
- Application properties
- MUnit tests
- Error handling
- Logging
- Database integrations
- CI/CD workflows
- Deployment configuration
- Project documentation

you define your API and integration requirements in:

muleforge.yaml
